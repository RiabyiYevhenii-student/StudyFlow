# Лабораторна робота 1
## Коротко про проєкт (основна інформація в звіті)

## Опис проєкту
StudyFlow - вебпланувальник навчальних завдань для студентів. Він допоможе студентам зберігати завдання з різних предметів, встановлювати та контролювати дедлайни та відповідно до цього планувати свій особистий та навчальний час.

Основна ідея - зібрати всі завдання, які розкидані по Classroom, Moodle, GoogleDisk і так далі в одному місці для комфорту.

## Основні цілі:
- Зберігати завдання в одному місці
- Допомога студентам контролювати дедлайни завдань та час відповідно
- Зручно відображати завдання (у календарному форматі)
- Відстежувати виконання своїх завдань

## Наша цільова аудиторія
- Студенти університетів чи коледжів
- Учні старших класів
- Люди, що навчаються самостійно та хочуть планувати свою роботу чи навчання
