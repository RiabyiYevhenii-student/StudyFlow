# StudyFlow - Лабораторна робота №2
## Опис
На цьому етапі було створено структуру сайту та 5 HTML-сторінок з навігацією між ними. Поки що сайт працює без CSS та JS
## Структура проєкту
- index.html - головна сторінка
- tasks.html - список завдань та форма додавання
- calendar.html - календар дедлайнів
- about.html - інформація про сервіс
- contacts.html - форма зворотного зв'язку
- images/ - логотип та зображення
- css/ - стилі сайту (лаб 3)
- js/ - скрипти (лаба 4)
## Запуск
Відкрити index.html у браузері
